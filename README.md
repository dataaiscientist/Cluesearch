# Cluesearch
Family memory keepers with 5+ year, mixed-source libraries cannot find a photo they clearly remember: search treats every clue as equally binding and leans on “when”, the clue they trust least. A miss never says which clue failed.

“Clue Search” finds the photo people remember by who and what, even when they guess when
